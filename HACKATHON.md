# Hackathon - SERV Edition 02, Reppo Track
## Integrations (verified 2026-11-04 against official docs)
- SERV Reasoning: POST https://inference-api.openserv.ai/v1/chat/completions, Bearer key from console.openserv.ai, model gpt-5.4-mini, system prompt required, response_format json_schema for the SecurityAssessment contract. Docs: docs.openserv.ai/serv-reasoning/api/
- Reppo Evaluation API (current contract, checked 2026-11-11): POST https://eval.reppo.xyz/api/v1/agents/evals {taskType:"response", input} -> 201 {id, status:QUEUED}; poll GET /agents/evals/{id} until COMPLETED (QUEUED|PROCESSING|COMPLETED|FAILED); result {score, decision, confidence, route, reason, rubric_scores}. Settles in ~30-90s, ~440 credits per evaluation (charged on COMPLETED), one pending evaluation per account (409), 402 = out of credits. The older /agents/eval-requests/* API (10+ min settlement, criteria, settlementMinutes) now returns 404 and is only reachable with REPPO_API_MODE=legacy. Docs: eval.reppo.xyz/agents.md
## Status in this environment
No SERV/REPPO keys were available during the build, so live calls are unverified here. The app reports not_configured honestly, never fabricates scores, and routes affected actions to REVIEW. To finish: add keys, run Integrations → Test connection, submit the demo, wait for settlement (about a minute), and record the real verdicts. Reppo credits are finite (REPPO_DAILY_BUDGET caps submissions per 24h).
